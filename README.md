# USaPeuskara · USaP Euskara entrenagailua

Batxilergoko ikasleek USaPeko Euskara eta Literatura II azterketa simulatzeko eta entrenatzeko web aplikazioa.

- `app/`: web aplikazioa (estatikoa; GitHub Pages-en argitaratzen da `gh-pages` adarretik: `git subtree push --prefix app origin gh-pages`). Domeinua: https://usapeuskara.berezuma.com (`app/CNAME`)
- `ereduak/`: 20 entrenamendu-eredu Markdown formatuan, txantiloiekin

Ereduak irakasle baten berrikuspenaren zain dauden zirriborroak dira. Xehetasunak: `ereduak/README.md` eta `app/README.md`.
